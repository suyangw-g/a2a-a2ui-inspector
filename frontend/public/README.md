# Frontend Public Assets (`frontend/public/`)

Static files and compiled output served by the FastAPI backend under `/static`.

---

## 🛠️ Files Overview

- **`index.html`**: Main HTML layout container for the inspector.
- **`styles.css`**: CSS design system tokens, A2UI surface card styles, and responsive full-page chat rules.
- **`script.js`**: Compiled JavaScript bundle generated by `npm run build` from `src/script.ts`.
- **[`renderer/`](./renderer/README.md)**: Embedded A2UI Composer renderer application.
