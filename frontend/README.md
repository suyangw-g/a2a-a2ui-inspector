# Frontend Package (`frontend/`)

This directory contains the user interface source code, TypeScript modules, styles, and build configuration for the A2A Inspector.

---

## 📁 Subdirectory Overview

- **[`src/`](./src/README.md)**: TypeScript source code, A2UI transformers, type definitions, and DOM components.
- **[`public/`](./public/README.md)**: HTML structure, CSS stylesheet, compiled `script.js` bundle, and embedded renderer assets.

---

## 🛠️ Build Commands

```bash
# Install dependencies
npm install

# Build JavaScript bundle with esbuild
npm run build
```
Generates `public/script.js`.
